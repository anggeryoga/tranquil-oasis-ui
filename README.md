# Tranquil Oasis UI

# LOVABLE.DEV — PIXEL-ACCURATE WEBSITE RECREATION PROMPT

Recreate the uploaded reference website as a **premium boutique hospitality / private retreat landing page**. The result should feel extremely close to the reference in composition, proportions, typography, spacing, image treatment, card construction, and overall art direction.

The design language is a blend of **quiet luxury, modern editorial web design, boutique travel, soft minimalism, and sophisticated Swiss-inspired UI**. It should feel calm, cinematic, tactile, warm, and expensive without becoming overly decorative.

Do NOT interpret this as a generic hotel website. The key visual identity is the unusual combination of **large cinematic photography + oversized editorial typography + tiny floating interface controls + asymmetric card layouts + pale lime-green accents + extremely generous white space**.

---

# STYLE OVERVIEW

Create a high-end private retreat / vacation rental experience called **TranquilQ**.

The visual mood should communicate:

- serenity

- privacy

- nature

- quiet luxury

- boutique hospitality

- curated travel

- warmth

- spaciousness

- sophisticated simplicity

- cinematic American-road-trip / desert-retreat photography

The interface should feel like a modern design studio created a luxury travel brand rather than a conventional hotel booking platform.

Use:

- large rounded image containers

- subtle off-white surfaces

- soft pastel lime-green interaction accents

- thin black outlines

- miniature pill buttons

- editorial typography

- italicized words within headings

- floating controls over photography

- asymmetric grids

- intentionally sparse layouts

- small, highly refined UI details

The overall page background should be **warm white / ivory**, not pure clinical white.

The photography should carry much of the emotional weight.

# COLOR SYSTEM

Use a restrained palette.

### Primary background

Warm ivory / soft white:

`#FAFAF7`

or a very close warm-neutral equivalent.

### Primary text

Near-black:

`#111111`

Use almost-black rather than absolute black.

### Accent

Very pale fluorescent / pastel lime:

`#DFFF8A`

Use this for:

- CTA pills

- active tags

- small highlighted controls

- navigation accents

- selected states

- subtle interaction indicators

The lime should remain soft and sophisticated rather than neon.

### Secondary surfaces

Use:

- `#F2F2EE`

- `#F5F5F2`

- translucent white

- soft gray

### Image overlays

Use translucent white with approximately 75–90% opacity for floating cards.

### Borders

Use extremely thin dark borders:

`1px solid rgba(0,0,0,0.75)`

Do not use heavy borders.

---

# TYPOGRAPHY

Typography is one of the most important aspects of the recreation.

Use a clean contemporary sans-serif such as:

- Inter

- Helvetica Neue

- Geist

- Satoshi

- Neue Montreal

Prefer **Geist / Helvetica Neue / Inter-like proportions**.

Headlines should be:

- very clean

- thin to regular weight

- large

- tightly tracked

- elegant

- sentence case

- occasionally split across multiple lines

Important words should use **italic styling**.

Example:

> Serenity's *Retreat.*  

> Your Private Oasis

and:

> Where *Coziness*  

> Meets Luxury

and:

> Your Gateway  

> to *Adventure*

and:

> The First *To Know*  

> *Everything* Growth

The italic treatment should feel editorial rather than decorative.

### Heading behavior

Large section headings should generally use:

- font-weight: 400

- tight line-height around 0.9–1.0

- letter-spacing around -0.04em

- responsive clamp-based sizing

Hero typography can reach approximately `64–82px` on desktop.

Section headings should be around `50–64px`.

Body copy should remain small and understated, generally `11–15px`.

Tiny interface labels can be `9–12px`.

# GLOBAL LAYOUT

The entire page should use a refined editorial grid.

Desktop:

- approximately 20–28px outer page padding

- max-width around 1440px

- centered content

- generous vertical section spacing

- asymmetric layouts rather than rigid conventional website sections

The reference is visually very wide and airy.

Use a 12-column conceptual grid but allow components to span unusual proportions.

Avoid making every section symmetrical.

The page should feel **art-directed**.

Use:

- large negative space

- overlapping elements

- cards that deliberately break the grid

- varying image sizes

- small floating UI elements

The hero is the most important visual element.

Approximately:

- width: 100%

- height: 500–600px desktop

# VISUAL EFFECTS

Use visual effects very carefully.

### Photography

Images should have:

- slightly desaturated tones

- warm highlights

- pastel colors

- soft contrast

- subtle filmic quality

Avoid hyper-saturated stock photography.

### Glass / translucency

Use subtle backdrop blur on floating UI.

Example conceptual styling:

`backdrop-filter: blur(14px)`

with translucent white surfaces.

### Shadows

Use extremely soft shadows:

- low opacity

- large blur

- minimal elevation

Never use dark dramatic shadows.

### Borders

Thin black or translucent gray outlines.

### Gradients

Use only subtle photographic overlays where necessary.

No obvious modern SaaS gradients.

# RESPONSIVENESS

Desktop should reproduce the uploaded composition as closely as possible.

### Desktop

- wide asymmetric grids

- floating cards

- large hero

- horizontal image groups

- extensive negative space

- editorial typography

### Tablet

Reduce:

- image dimensions

- headline sizes

- gaps

- number of simultaneous floating controls

Maintain the asymmetric character.

### Mobile

Do not simply shrink the desktop design.

Recompose intelligently:

- navbar becomes compact

- hero remains large and cinematic

- floating elements reposition inside hero

- hero headline scales down

- horizontal card groups become horizontal scrolling galleries or stacked cards

- two-column feature layouts become stacked

- bento cards become a clean vertical sequence

- newsletter remains centered

Preserve the visual identity rather than forcing everything into identical cards.

---

# ANIMATIONS

Use **Framer Motion** for subtle, premium motion.

Animations should never feel like a flashy SaaS dashboard.

### Page entrance

Elements should fade and translate upward by approximately 10–20px.

Use staggered reveals.

### Hero

Floating labels can have extremely subtle floating motion.

Hero image may have a very slow scale/parallax effect.

### Cards

On hover:

- image scales approximately 1.02–1.04

- card moves upward 1–3px

- arrow rotates or translates slightly

### Buttons

On hover:

- subtle background transition

- arrow shifts slightly right/up

- tiny scale change

### Scroll

Use restrained scroll-triggered reveals for:

- headings

- image groups

- floating cards

- statistics

Avoid excessive parallax.

Avoid bouncing.

Avoid large spring animations.

---

# INTERACTION DIRECTION

Use:

- button micro-interactions

- subtle opacity transitions

- smooth navigation

- accessible focus states

The design should remain calm even when interactive.
